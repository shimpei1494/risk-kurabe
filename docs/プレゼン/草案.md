# あなたは自分の住んでいる地域の災害リスク把握してますか？

# 災害の多さ
・日本は地震が多い
・大雨による水害も増えてきている
→より被害を抑えるために地域の災害リスクを把握する必要がある

# でも、災害リスクの情報って身近じゃない
調べようと思うと結構面倒だし、どのサイトを見たらいいのかよくわからないということも

# １箇所だけでなく、他の地点と比較したい場合はさらに調べるハードルが上がる
自分自身引越しを検討する際に、もっと気軽に災害リスクを比較できたら便利で嬉しいと思った

# 課題解決のために作ったアプリ
「TOKYOりすくらべ」は、気になる地点の災害リスクを手軽に確認・比較できるWebサービスです。住所検索または地図から1〜3地点を選び、関東1都6県の洪水浸水想定と、東京都内では地震時の総合危険度・建物倒壊危険度・火災危険度を同じ画面で比較できます。地図上でも各指標を切り替えて確認でき、AIが表示中の公開データをわかりやすく説明することも可能です。出典や公式ハザードマップへの導線も備え、詳しく調べるための入口として利用できます。

# 技術選定
（以下の内容をコンパクトに記載し、かつ発表ではアプリの魅力について説明したいので、発表での説明は割愛する）
TypeScript／TanStack Startで画面とサーバー処理を一体化し、Yahoo!ジオコーダAPIやAIの認証情報をCloudflare Workers側に保護。MantineはレスポンシブUI、MapLibre GL・国土地理院公式タイル・PMTiles・FlatGeobufはGISの表示と必要範囲だけの取得に適するため採用しました。Workers／R2は個人でも低運用負荷で配信可能。OpenUI LangでAI出力を定義済みUIに制約し、Vite+で開発・テスト・Lint・ビルドを統一しました。
