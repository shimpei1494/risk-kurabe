# 公開GISデータの来歴と生成

## 目的

ハッカソン版`risk-data-v2`で使用する公開GISデータの取得元、収録範囲、加工方法と
既知の制約をまとめる。洪水の実行時判定は公式統合タイルへ切り替えており、A31a成果物は
既存v2の保管・再現用として残している。入力ファイルのURL、サイズ、取得日、ライセンス、SHA-256は
[`sources.lock.json`](../../data-manifest/sources.lock.json)を正本とする。

## 現在利用するデータ

| データ | 対象 | 生成結果 | 状態・制約 |
| --- | --- | --- | --- |
| A31a 想定最大規模洪水浸水深 | 関東1都6県 | 都県別FlatGeobuf 7件、地図用PMTiles 1件、計1,028,003地物 | 洪水予報河川・水位周知河川を収録。「その他の河川」は含まず、全都県とも部分収録 |
| 東京都地域危険度 第9回 | 東京都 | 全町丁目FlatGeobuf 1件、総合・建物倒壊・火災PMTiles各1件 | 5,192町丁目、51区市町村。島しょ部は対象外 |

実行時の配置先は次のURLである。

```text
https://pub-bc1c84661928416fbcde6535c9039c50.r2.dev/risk-data/v2/
```

`manifest.json`は出典と成果物情報、`coverage.json`は収録範囲、`checksums.json`は
12件のGIS成果物のサイズとSHA-256を保持する。

## A31a 洪水浸水想定区域（想定最大規模）

現在のアプリ実行時は、A31aを直接地点判定には使用せず、国土地理院が配信する
「洪水浸水想定区域（想定最大規模）」の統合ラスタタイルを使用する。統合タイルは国管理河川、
都道府県管理河川、その他河川を統合した表示レイヤーであり、地図表示と地点判定に同じデータを用いる。
配信URLと利用条件は[ハザードマップポータルサイトのオープンデータ配信ページ](https://disaportal.gsi.go.jp/hazardmap/copyright/opendata.html)を参照する。

以下は旧v2のA31a成果物を生成・検証するための記録である。

- 提供者: 国土交通省
- 配布元: 国土数値情報 A31a 2025年度
- 入力形式: 都県別GeoJSON ZIP 7件
- 対象: 茨城、栃木、群馬、埼玉、千葉、東京、神奈川
- 取得日: 2026-07-17
- 利用条件: CC BY 4.0
- 収録区分: 洪水予報河川・水位周知河川の想定最大規模

河川番号、河川名、管理者、元の浸水深区分を取得する。浸水深は実測値へ変換せず、
公開元の区分ラベルを表示する。複数河川が重なる地点は最も深い区分を主結果とし、
一致した全河川を根拠として保持する。

## 東京都「地震に関する地域危険度測定調査（第9回）」

- 提供者: 東京都都市整備局
- [東京都オープンデータカタログ](https://catalog.data.metro.tokyo.lg.jp/dataset/t000008d0000000012)
- [公式データ配布元](https://www.funenka.metro.tokyo.lg.jp/area-hazard-level/regional-risk-list/)
- 基準時点: 2022年9月
- 入力形式: 全町丁目Shapefile ZIP 1件、全町丁目CSV 1件
- 取得日: 2026-07-17
- 利用条件: CC BY 4.0

区市町村名と町丁目名を組み合わせた`town_key`でCSVと形状を1対1結合し、地盤分類、
建物倒壊危険度、火災危険度、災害時活動困難係数、総合危険度を正規化する。
アプリでは総合危険度を主表示し、残りを内訳・根拠として表示する。地図では総合、
建物倒壊、火災の公式ランク1〜5を切り替えられる。

総合危険度は建物倒壊危険量と火災危険量を合算し、道路等の整備状況による
災害時活動困難係数を乗じた東京都内の相対指標である。洪水を含む災害横断の
総合評価ではない。

## 加工・検証

1. 入力のサイズとSHA-256を照合する。
2. GDALで不正形状を修復し、EPSG:4326へ統一する。
3. 属性を正規化し、空形状、件数、属性スキーマを検証する。
4. 地点検索用FlatGeobufと地図用PMTilesを生成する。
5. マニフェスト、カバレッジ、チェックサムを生成する。
6. `risk-data/v2/`へアップロードし、HTTP Range取得を検証する。

```bash
vp run data:a31a:build
vp run data:tokyo-risk:build
vp run data:a31a:validate
vp run data:tokyo-risk:validate
vp run data:upload
vp run data:a31a:verify-remote
vp run data:tokyo-risk:verify-remote
```

## 既知の制約

- A31aは関東全河川の網羅データではない。「その他の河川」を含まないため、値が
  ないことを浸水リスクなしとは解釈しない。
- 東京都地域危険度は東京都内の相対評価であり、東京都外の安全性を示さない。
  島しょ部は収録対象外である。
- 座標だけから都県コードを決定する行政界データは未収録である。通常フローでは
  Yahoo住所検索の都道府県コードを使う。結果画面のピン移動は近隣探索として
  元の位置から2km以内に制限し、元の都県コードを維持する。都県境をまたぐ場合は
  住所検索からやり直す。自由なピン移動には行政界追加または逆ジオコーディングが
  必要になる。

## 退役したデータ

旧`risk-data-v1`に収録したA53頻度別洪水浸水深は、対象水系が限られ、想定最大規模
より判定できる範囲が狭い一方で、画面上の「判定データなし」と取得量が増えるため
`v2`から除外した。経緯と容量は[ADR-0027](../adr/0027-a53頻度別浸水を削除する.md)
に記録する。
