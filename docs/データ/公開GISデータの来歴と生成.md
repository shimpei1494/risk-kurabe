# 公開GISデータの来歴と生成

## 目的

現在のアプリが利用する公開GISデータの取得元、配信方法、加工手順と既知の制約をまとめる。
固定成果物の入力URL、サイズ、取得日、ライセンス、SHA-256は
[`sources.lock.json`](../../data-manifest/sources.lock.json)を正本とする。

| データ | 対象 | 配信・生成結果 | 状態・制約 |
| --- | --- | --- | --- |
| 洪水浸水想定区域（想定最大規模） | 関東1都6県の検索対象地点 | ハザードマップポータルサイトの公式統合ラスタタイル | 国・都道府県・その他河川を統合した公開タイルを調査時に取得する |
| 東京都地域危険度 第9回 | 東京都 | 全町丁目FlatGeobuf 1件、総合・建物倒壊・火災PMTiles各1件 | 5,192町丁目、51区市町村。島しょ部は対象外 |

東京都地域危険度の固定成果物は次のURLに配置する。

```text
https://pub-bc1c84661928416fbcde6535c9039c50.r2.dev/risk-data/v3/
```

`manifest.json`は出典と成果物情報、`coverage.json`は収録範囲、
`checksums.json`は4件の固定GIS成果物のサイズとSHA-256を保持する。

## 洪水浸水想定区域（想定最大規模）

- 提供者: 国土交通省・国土地理院
- [ハザードマップポータルサイトのオープンデータ配信ページ](https://disaportal.gsi.go.jp/hazardmap/copyright/opendata.html)
- 配信形式: PNGラスタタイル
- 利用条件: 公共データ利用規約（PDL1.0）
- 地点判定ズーム: 17

地図表示と地点判定には、国土地理院が配信する「洪水浸水想定区域（想定最大規模）」の
公式統合タイルを使用する。地点判定ではピン座標に対応する画素色を公式の浸水深区分へ
変換し、周囲25mの画素も確認して境界警告を判定する。浸水深は実測値へ変換せず、
`0.5m以上3.0m未満`などの公開区分として表示する。

公式タイルは更新型の外部配信であり、アプリのR2へ複製しない。取得できない場合は
区域外とせず、判定不能として扱う。透明画素も「安全」を意味しないため、必要に応じて
自治体の最新ハザードマップで確認する。

## 東京都「地震に関する地域危険度測定調査（第9回）」

- 提供者: 東京都都市整備局
- [東京都オープンデータカタログ](https://catalog.data.metro.tokyo.lg.jp/dataset/t000008d0000000012)
- [公式データ配布元](https://www.funenka.metro.tokyo.lg.jp/area-hazard-level/regional-risk-list/)
- 基準時点: 2022年9月
- 入力形式: 全町丁目Shapefile ZIP 1件、全町丁目CSV 1件
- 取得日: 2026-07-17
- 利用条件: CC BY 4.0

区市町村名と町丁目名を組み合わせた`town_key`でCSVと形状を1対1結合し、地盤分類、
建物倒壊危険度、火災危険度、災害時活動困難係数、総合危険度を正規化する。
アプリでは総合危険度を主表示し、残りを内訳・根拠として表示する。地図では総合、
建物倒壊、火災の公式ランク1〜5を切り替えられる。

総合危険度は東京都内の相対指標であり、洪水を含む災害横断の総合評価ではない。

## 加工・検証

1. 入力のサイズとSHA-256を照合する。
2. GDALで不正形状を修復し、EPSG:4326へ統一する。
3. 東京都地域危険度のShapefileとCSVを結合し、件数と属性スキーマを検証する。
4. 地点検索用FlatGeobufと地図用PMTilesを生成する。
5. V3のマニフェスト、カバレッジ、チェックサムを生成する。
6. R2へアップロードし、HTTP Range取得を検証する。

```bash
vp run data:tokyo-risk:download
vp run data:tokyo-risk:build
vp run data:tokyo-risk:validate
vp run data:tokyo-risk:upload
vp run data:tokyo-risk:verify-remote
```

## 既知の制約

- 公式統合タイルは浸水深区分を示すもので、個別建物や敷地内の高低差を表さない。
- タイルの拡大表示は元データの精度向上を意味しない。
- 東京都地域危険度は東京都内の相対評価であり、東京都外の安全性を示さない。
  島しょ部は収録対象外である。
- 座標だけから都県コードを決定する行政界データは未収録である。通常フローでは
  Yahoo住所検索の都道府県コードを使う。結果画面のピン移動は元の位置から2km以内に
  制限し、元の都県コードを維持する。

過去に利用したデータ方式と移行判断はADRに履歴として残し、現在の生成・配信手順には
含めない。
