# ブランド画像の生成メモ

組み込みの `image_gen` を使用し、コンセプト3案目
「紙地図を調べるリス」を参照して生成した。
画像内の文字は生成せず、OGPのSVGで正確に組版してからJPEGへ変換している。

## OGP・ヒーロー

- 用途: 1200×630のOGPおよび文字なしの横長キービジュアル
- 構図: 左43%を文字用の静かな紙面、右57%へリス・地図・2つのドングリ地点を配置
- 表現: 紙工作、東京ティール、青と橙の半透明データレイヤー
- 制約: リスは1匹、地点は2つ、安全・危険の優劣を描かない、画像生成時は文字なし

`ogp-background.png` が生成・縮小後の背景、`ogp.svg` が文字組みを含む編集可能な正本。
配信用の `public/brand/ogp.jpg` は、SVGを1200×630で描画してJPEG品質82で圧縮している。

## アプリアイコン

- 用途: 512pxおよびApple Touch Icon
- 構図: リス、折り地図、青と橙のドングリ地点を円形にまとめる
- 表現: 紙工作の質感を保ちつつ、キービジュアルより単純化
- 制約: リスは1匹、地点は2つ、文字・盾・チェックマークなし

採用画像は `public/brand/app-icon-512.png`。Apple Touch Iconはここから縮小している。

## favicon

- 用途: 16px、32px、192px
- 構図: 濃いティールの角丸背景に、リスの顔・しっぽ・2つの小さなドングリ地点
- 表現: 4〜5色の太い形へ単純化し、小サイズで判別できるようにする
- 制約: 地図や虫眼鏡を省略し、細線・細かな毛並み・文字を使わない

採用画像は `public/brand/icon-192.png`。16px・32px版も同じ構図から縮小している。
