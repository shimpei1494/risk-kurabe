# ADR-0029: 地図上の値確認と近隣地点の再判定を追加する

- 状態: 採用
- 決定日: 2026-07-31
- 関連: ADR-0019、ADR-0021、ADR-0022

## コンテキスト

結果地図は公開データの階級を色で表しているが、凡例と色の照合だけでは、ピン地点や
周辺の値をすぐに読み取りにくい。また、近くへピンを動かした場合の結果を比較するには、
住所入力からやり直す必要がある。

一方、地点判定用データと地図表示用データは分離している。地図の色を読むだけで正式な
調査結果を置き換えると、境界判定や取得失敗の扱いが不一致になる。座標から都県コードを
確定する行政界データも未収録である。

## 決定

- 各ピンの位置には、表示中のPMTilesから読んだ浸水深区分または東京都公式ランクを
  常時表示する。
- PCでは地図上のホバー、タッチ端末ではタップにより、任意地点の階級を表示する。
- 結果地図のピンをドラッグ可能にする。ドラッグだけでは結果を変更せず、
  `この位置で再判定`を押したときだけFlatGeobufによる正式な地点判定を実行する。
- 再判定後は同じ地点枠の座標と結果を置き換え、1〜3地点の比較へ反映する。
- 近隣探索に限定し、移動距離は元の位置から2km以内とする。住所表示と都県コードは
  元の検索結果を維持するため、都県境をまたぐ探索は住所検索からやり直す。

## 結果

- 色覚や凡例の記憶だけに頼らず、ピン地点と周辺の公開データ階級を確認できる。
- ドラッグ中の表示値は探索用、確認後の結果は既存の地点判定処理という役割が明確になる。
- 追加の外部APIやGISデータは不要で、再判定時だけ既存のR2 Range取得が発生する。
- 2km以内でも都県境を越える可能性は残るため、境界付近では住所変更からの再検索を
  案内する。全国的な自由移動には行政界データまたは逆ジオコーディングが必要である。
