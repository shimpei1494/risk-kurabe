# ADR-0028: 総合危険度地図をv2へ追加する

> 固定データ版に関する決定はADR-0030により置き換えた。この文書は意思決定履歴として残す。

- 状態: 置換済み（ADR-0030のV3固定成果物へ統合）
- 決定日: 2026-07-30
- 関連: ADR-0026

## コンテキスト

結果画面では「東京都・地震時の総合危険度」を主表示しているが、地図は内訳である
建物倒壊危険度と火災危険度だけを切り替えられる。東京都地域危険度FGBには
`overall_rank`がすでに収録されており、追加の外部データなしで主題図を生成できる。

通常は固定データの構成変更時に新しいデータ版を作る。一方、`risk-data-v2`は公開
直後で利用者がおらず、A31aを含む約1.1GBを`v3`へ再配置する負荷に対し、追加する
総合危険度PMTilesは6,285,600 bytes（約6.0 MiB）である。

## 決定

- `overall_rank`だけを持つ`map/tokyo-overall-risk.pmtiles`を生成する。
- 地図切替を「最大浸水、地震総合、建物倒壊、火災」の順にする。
- 今回に限り、利用開始前の`risk-data-v2`へ成果物とメタデータを追加する。
- A31aは再アップロードせず、東京都地域危険度の成果物だけを個別配置する。

## 結果

- 結果の主表示と地図で同じ総合危険度ランクを確認できる。
- R2の増加量は約6.0 MiB、個別アップロード対象は約34 MiBに収まる。
- `v2`の内容が公開後に一度更新される例外が生じる。利用者やキャッシュとの互換性を
  考慮する必要がある今後の変更では、新しい版を作る原則へ戻す。
