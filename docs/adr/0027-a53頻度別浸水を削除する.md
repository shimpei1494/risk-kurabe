# ADR-0027: A53頻度別浸水を削除する

> ADR-0030により洪水データ方式全体を置き換えた。この文書は意思決定履歴として残す。

- 状態: 採用
- 決定日: 2026-07-30
- 置換対象: ADR-0018、ADR-0020・0021・0025のA53に関する部分

## コンテキスト

A53頻度別洪水浸水深は、1/10〜1/200の6降雨規模を表示していた。しかし、公開・
収録されている水系が限られ、A31a想定最大規模より判定できる範囲が狭い。比較地点の
多くで「判定データなし」や「未公開」が並び、ユーザーが最大浸水深との関係を
読み違える可能性がある。

旧`risk-data-v1`のA53成果物はFlatGeobuf 6件とPMTiles 6件の計12件、
173,690,117 bytes（約165.6 MiB）である。1地点の調査では条件により最大6件の
追加Range取得が発生する。

## 決定

- A53を画面、地点判定、比較、地図、キャッシュ、型、テストから削除する。
- A53の入力ロック、変換、検証、アップロード、リモート検証の処理を削除する。
- 残すA31aと東京都地域危険度を`risk-data-v2`として再生成する。
- アプリを`v2`へ切り替えて検証した後、R2の旧`risk-data/v1`を削除する。
- 頻度別浸水を将来機能として計画へ残さない。

## 理由

表示項目の多さよりも、広く判定できて説明しやすい指標を優先する。A53だけを旧版から
消すと版付きimmutableスナップショットを後から変更することになるため、データ構成の
変更を新しい版として分離する。

## 結果

- R2の純削減量は約165.6 MiBとなる。`v2`切替まで一時的に約1.04 GiBの重複が生じる。
- 1地点あたりのA53検索がなくなり、通信回数と判定待ち時間が減る。
- 画面は想定最大規模洪水と東京都地震地域危険度へ集中する。
- A31aが含まない「その他の河川」という洪水カバレッジ上の制約は残る。
