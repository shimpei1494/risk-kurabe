# ADR-0030: 洪水を公式統合タイルへ移行し固定データをV3にする

## 状態

採用

## 背景

都県別の洪水ポリゴンだけでは、国管理河川やその他河川を含むハザードマップポータル
サイトの表示と一致しない地点があった。洪水の比較精度を公式サービスへ近づけながら、
個人運用で大容量ポリゴンを継続的に更新する負荷を抑える必要がある。

## 決定

- 洪水浸水深の地図表示と地点判定には、ハザードマップポータルサイトの
  「洪水浸水想定区域（想定最大規模）」公式統合ラスタタイルを使用する。
- 地点判定はブラウザでタイル画素を読み取り、公式の浸水深区分として表示する。
- 周囲25mを標本化し、中心画素と区分が異なる場合は境界警告を表示する。
- R2の固定データV3には東京都地域危険度のFlatGeobuf、3種類のPMTiles、
  マニフェスト、カバレッジ、チェックサムだけを配置する。
- 旧洪水ポリゴンの生成・判定コード、入力ロック、R2成果物は退役させる。

## 影響

- 国・都道府県・その他河川を統合した公式表示と同じタイルを参照できる。
- 河川名や管理者など、ラスタタイルに含まれない属性は表示しない。
- 公式タイルが取得できない場合は、区域外ではなく判定不能として扱う。
- 過去のデータ構成を前提とするADRは意思決定履歴として残るが、現行仕様としては
  このADRが置き換える。

## 置き換える主なADR

- ADR-0017 公開GISデータはR2へ保存する
- ADR-0018 旧洪水データから水系を特定して頻度別浸水を判定する
- ADR-0019 GIS判定はブラウザで実行する（公式タイルのブラウザ判定として継続）
- ADR-0020 地図には選択中の1指標だけを表示する（表示方針は継続）
- ADR-0021 浸水深は元データの区分として表示する（区分表示方針は継続）
- ADR-0027 頻度別浸水を削除する
- ADR-0028 総合危険度地図を旧固定データ版へ追加する
