# ADR-0026: 東京都の地震時総合危険度を主表示にする

- 状態: 採用
- 決定日: 2026-07-30

> 総合危険度地図を追加しない判断は、ADR-0028で変更した。
- 置換対象: ADR-0022

## コンテキスト

東京都の「地震に関する地域危険度測定調査（第9回）」は、建物倒壊危険度、火災危険度、災害時活動困難係数および総合危険度を町丁目ごとに提供している。総合危険度は、建物倒壊危険量と火災危険量を合算し、道路等の整備状況による災害時活動困難係数を乗じた、東京都内の地震に関する相対指標である。

ハッカソン版の固定FGBにはこれらの属性がすでに収録されている。追加の入力データなしで総合危険度を表示できる一方、単に`総合危険度`と表示すると、洪水や土砂災害などを含むアプリ独自の総合スコアと誤解される可能性がある。

## 決定

- 画面上の名称は`東京都・地震時の総合危険度`とする。
- 洪水と東京都の地震地域危険度を別セクションに分ける。
- 東京都の地震地域危険度セクションでは、総合危険度ランクを折りたたまない主表示とする。
- 総合危険度の近くに、`建物倒壊・火災と災害対応活動のしにくさをまとめた東京都内の相対評価であり、洪水などは含まない`ことを常時表示する。
- 建物倒壊危険度、火災危険度、災害時活動困難係数および地盤分類は、総合危険度の内訳・根拠として展開表示する。
- 地盤分類には、町丁目単位の分類であり、個別敷地の地盤調査や液状化判定ではないことを併記する。
- 総合危険度、建物倒壊危険度および火災危険度には、それぞれ公式のランク1〜5と`東京都内における相対評価`を表示する。
- ランク1を`安全`、ランク5を絶対的な`危険`または被災確率として表現しない。
- 東京都外は各値を最低ランクへ変換せず、`対象外（東京都のみの指標）`とする。
- 東京都内と東京都外の地点を、東京都地域危険度によって順位付けしない。
- 総合危険度についても半径25mの境界警告を判定する。
- AI要約へ含める場合も、東京都内の地震に関する相対評価であることを保持し、洪水等を含む総合評価へ読み替えない。

## 地図

- A31aを初期地図とするADR-0020の方針を維持する。
- Day 8第2段階では総合危険度専用PMTilesを追加しない。
- 内訳である建物倒壊危険度と火災危険度は、既存PMTilesを使って引き続き個別に選択できる。
- 将来、総合危険度地図を追加する場合は、固定データ版を更新し、既存の版付き成果物を上書きしない。

## データとキャッシュ

- 既存FGBの`overall_score`、`overall_order`、`overall_rank`、`activity_difficulty`および`ground_classification`を使用する。
- 入力データ、FGBおよび既存PMTilesは変更しない。
- 地点調査結果の契約変更に合わせ、判定ロジック版とsessionStorageスキーマ版を更新する。
- 古いキャッシュ結果には総合危険度がないため、版不一致として破棄し、現在データから再判定する。

## 結果

- 東京都オープンデータが提供する公式の総合指標を、建物倒壊と火災の重複表示より先に理解できる。
- 必要な利用者は、総合危険度の内訳と地盤・道路状況の根拠まで確認できる。
- 洪水を含むアプリ独自スコアではないことを表示構造と文言の両方で区別できる。
- R2成果物を増やさずに実装できる。
- 総合危険度そのものの主題図は、この段階では表示できない（後にADR-0028で追加）。
